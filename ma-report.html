Model and measures

How this report would be built in Power BI

Star schema with one fact table at state × month grain, loaded from the CMS Medicare Monthly Enrollment API. Dim_Date marks CMS annual rows separately from monthly rows, and Dim_Geography separates national from state rows so U.S. benchmarks never double count.

Fact_Enrollment: TOT_BENES, MA_AND_OTH_BENES, ORGNL_MDCR_BENES, PRSCRPTN_DRUG_MAPD_BENES, PRSCRPTN_DRUG_PDP_BENES, PRSCRPTN_DRUG_TOT_BENES
Dim_Geography: StateCode, StateName, GeoLevel
Dim_Date: Year, Month, PeriodType (Annual / Monthly)

MA Share % =
DIVIDE ( SUM ( Fact_Enrollment[MA_AND_OTH_BENES] ),
         SUM ( Fact_Enrollment[TOT_BENES] ) )

MA Share % (U.S.) =
CALCULATE ( [MA Share %],
    REMOVEFILTERS ( Dim_Geography ),
    Dim_Geography[GeoLevel] = "National" )

MA Share Change pp =
VAR FirstYr = CALCULATE ( [MA Share %], Dim_Date[Year] = 2013 )
VAR LastYr  = CALCULATE ( [MA Share %], Dim_Date[Year] = 2025 )
RETURN ( LastYr - FirstYr ) * 100

MA-PD Share of Part D =
DIVIDE ( SUM ( Fact_Enrollment[PRSCRPTN_DRUG_MAPD_BENES] ),
         SUM ( Fact_Enrollment[PRSCRPTN_DRUG_TOT_BENES] ) )

Source: CMS, Medicare Monthly Enrollment (release through June 2026), pulled September 29, 2026. 50 states and DC; territories excluded.

"MA & other plans" is CMS's Medicare Advantage and Other Health Plans category, which also includes cost plans and PACE. Annual figures are CMS's annual rows; KPI cards use the June 2026 month.
