Model and measures

How this report would be built in Power BI

One fact table at state × year grain from the CMS Geographic Variation API, filtered to the all-ages rows. Per-capita columns are already rates, so the measures weight them by fee-for-service beneficiaries instead of summing them. That keeps totals right when several states are selected.

Fact_GeoVariation: BENES_OM_CNT, TOT_MDCR_STDZD_PYMT_PC, IP / OP / SNF / HH / HOSPC / EM _MDCR_STDZD_PYMT_PC, ACUTE_HOSP_READMSN_PCT, ER_VISITS_PER_1000_BENES, IP_CVRD_STAYS_PER_1000_BENES
Dim_Geography: StateCode, StateName, GeoLevel
Dim_Year: Year

Std Spend per Beneficiary =
DIVIDE (
    SUMX ( Fact_GeoVariation,
        Fact_GeoVariation[TOT_MDCR_STDZD_PYMT_PC]
          * Fact_GeoVariation[BENES_OM_CNT] ),
    SUM ( Fact_GeoVariation[BENES_OM_CNT] ) )

Spend vs U.S. % =
VAR US = CALCULATE ( [Std Spend per Beneficiary],
    REMOVEFILTERS ( Dim_Geography ),
    Dim_Geography[GeoLevel] = "National" )
RETURN DIVIDE ( [Std Spend per Beneficiary] - US, US )

Spend Rank =
RANKX ( ALLSELECTED ( Dim_Geography[StateName] ),
        [Std Spend per Beneficiary], , DESC, DENSE )

Spend Growth since 2014 % =
VAR Y0 = CALCULATE ( [Std Spend per Beneficiary], Dim_Year[Year] = 2014 )
RETURN DIVIDE ( [Std Spend per Beneficiary] - Y0, Y0 )

Source: CMS, Medicare Geographic Variation by National, State & County (2014–2024, all ages), pulled September 29, 2026. 50 states and DC.

Covers Original Medicare only; Medicare Advantage enrollees are not included. Standardized spending removes geographic price differences (such as local wage indexes) so states compare on use of services. "Other" in the spending mix is total standardized spending minus the six categories shown (for example imaging, tests, procedures, equipment and ambulance).
